# Release notes

Copy for the Play Console **"What's new in this release"** field. Limit is
**500 characters per language**; counts are noted below each block.

Release notes are user-facing. Write what changed for the learner, not what
changed in the code — "fixed 384 cards that showed a doubled article" means
nothing to someone who never saw the bug.

---

## v1.0.0 (versionCode 1) — first production release

```
Learn German with 11,549 flashcards across 11 decks, from Goethe A1 to
professional and IT German.

• Spaced repetition brings each card back just before you forget it
• German pronunciation on every card, from your phone's own voice
• Articles, plurals, full conjugations and example sentences
• Search in either language — umlauts optional
• Streaks, activity history and a forecast of what is due

Works entirely offline. No account, no ads, no tracking.
```

## Closed testing

Testers read these, so say what you want them to try.

```
Thanks for testing DeutschCards.

Please check:
• The speaker button on a card actually speaks German
• A study session saves your progress after you close the app
• Search finds "über" when you type "uber"

Tell us your phone model if audio does not work — text-to-speech voices vary
by manufacturer.
```

## Template for later updates

Lead with what the learner gains. Group into "New" and "Fixed" only when there
is enough of both to be worth the headings.

```
New in this version:
• <the thing someone would notice>
• <the next thing>

Fixed:
• <a problem a user actually hit>
```

Keep each line under about 80 characters so it does not wrap awkwardly on a
phone.
